# 7.7. Applications

Applications are written in RISC-V assembly, and all their behavior must be in software, so that it can be changed by editing the program only.

The wrapper may contain only the clock, reset, input conditioning and GPIO buffers, with no hardware that performs part of an application. No build files are provided, so students write and assemble their own programs.

Choose one or more applications from the table below. Their points add up to a maximum of 5. These applications are suggestions. Students may propose their own application, and the TA assigns its level and points individually.

**Table 17: Suggested applications and their points.**
